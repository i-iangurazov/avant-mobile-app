## Селекты и формы — фактическая инвентаризация

Dropdown/picker библиотека не найдена; текущие варианты выбора реализованы через Pressable, chips, segmented controls и списки карточек. Поэтому «открыть/закрыть dropdown» неприменимо конкретным постоянно видимым вариантам. Searchable long picker не является реализованной функцией.

Одинаковая selected semantics, контраст, зоны касания и inline ошибки. Это рекомендация, не уже внесённое исправление.

## Карта

Провайдер2GIS widget, native react-native-webview, web iframe. Публичный widget URL, не SDK с ключом; поэтому проверка ограничений native map API key пока N/A для этой интеграции. Release WebView/сеть/подписи не проверены. Геолокация приложением не запрашивается: ручной список6магазинов остаётся доступным.

Native предусмотрены loading/onError/onHttpError и кнопка retry; web iframe собственного fallback не имеет. Недоступность провайдера, неопределённо долгий loading, nested gestures, GPS сценарии стороннего виджета и возврат из внешнего2GIS не проверены на устройствах. WebView имеет mixedContentMode=always/originWhitelist=*, навигационные ограничения требуют ревизии. Внешние ссылки всех store cards ведут на общий поиск, а не гарантированно выбранный firm ID. Наличие обязательных подписей на скриншоте видно, но накладки затрагивают низ карты; соответствие лицензии отдельно не установлено. Обязательную атрибуцию убирать нельзя.

## Фигуры, иконки, изображения

- Геометрический знак на welcome/баннере — `src/imports/avant-icon.png`, **брендовый asset**, не случайная фигура. Предложение удалять его без решения бренда отсутствует.
- Закруглённая рамка с `image-outline` — `ProductImagePlaceholder`, семантическое обозначение отсутствующего фото. Причина в пустых API images; D12 относится к наполнению/площади placeholders.
- Цветные круги статусов заказа, checkbox/radio, QR и иконки направлений имеют назначение. QR нельзя заменять декоративным рисунком.
- После правильной раздачи Ionicons TTF квадраты вместо glyphs не воспроизвелись. Первый пробный локальный static harness не декодировал пробелы в URL шрифта; это исправление **средства проверки**, не продукта. Тот снимок в итоговую галерею не включён и дефектом приложения не считается.
- Основной набор — Ionicons. Изображения реальных товаров в проверенной выборке отсутствуют, поэтому crop/orientation/loading error реальных photo assets не подтверждены.

## Компактные правила по существующему бренду

Сохранить светлый фон, оранжевое основное действие и синий профессиональный раздел. Базовые отступы8/12/16/24, текст15/17/20/24;11px оставить только второстепенным метаданным с достаточным контрастом. Одна форма поля с label/error, один набор button states; ясный заголовок на экран. Для radio/chips и обычных карт ограничить разброс скруглений/теней. Иконка нужна для поиска/карты/корзины/статуса; повторяющиеся swap-vertical у всех3sort chips можно убрать. Не добавлять градиенты/анимации/геометрию ради заполнения пространства. Предложения не представлены как screenshots исправленного UI.
