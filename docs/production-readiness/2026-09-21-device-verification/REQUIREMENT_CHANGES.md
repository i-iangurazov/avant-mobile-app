# Уточнения владельца —21.09.2026

Это изменения требований в ходе физической проверки, а не переписывание исходного аудита.

- Регистрация/вход: владелец отменил подтверждение номера SMS-кодом и выбрал простой телефон/пароль. Вариант проверки через Telegram также отвергнут. Новые аккаунты имеют phone_verified_at=NULL. Телефон — идентификатор входа/заявленный контакт, не доказательство личности; публичные поля role/verified игнорируются. Права администратора назначаются только доверенной операцией в БД; телефон и SMS не являются источником прав.
- Восстановление: реализована бесплатная ручная очередь в существующей админке приложения. Это не Telegram-админка и не автоматическая email/SMS доставка. Анонимная заявка даёт одинаковый ответ для существующего/неизвестного аккаунта. Администратор повторно вводит свой пароль и записывает основание проверки владельца; одноразовая ссылка256бит действует30минут, хранится только хеш, после использования завершает прежние сессии. Пользователь может открыть ссылку или вставить её в экран восстановления. Запрос по одному номеру никогда не меняет пароль.
- До production владелец должен назначить ответственного, утвердить проверку личности независимо от введённого номера/текста заявки и канал передачи ссылки. Полное рабочее восстановление через настоящую поддержку пока не подтверждено. Нельзя считать заявленный номер, имя или публичный номер заказа достаточной проверкой. Политику удержания contact_note/review_note необходимо включить в утверждённые privacy/retention условия.
- При смене номера текущий пароль обязателен; старые сессии и незавершённые recovery links отзываются только для этого аккаунта. Удаление требует сессии, текущего пароля, явного подтверждения и утверждённого deletion document version. SMS UI/provider удалены, прежний challenge route отвечает410. Legacy OTP таблица сохраняется ради недеструктивной миграции, новых challenge записей продукт не создаёт.
- Исправлена отдельная ошибка ручного ввода телефона: +996 больше не дублируется, неполный префикс сохраняется, поле можно очистить, лишние цифры не обрезаются в чужой корректный номер. Четыре формата проверяются посимвольно и вставкой.
- Иконка меню: исходный бренд сохраняется; белый adaptive background и18% inset foreground, для обычной и круглой маски. Expo plugin применяется при prebuild; bitmap не перерисован.
- По прямому уточнению владельца область изображения товара всегда1:1, включая placeholder и ошибку загрузки, в карточке и деталях. Старое уменьшение64/100px отменено. Это изменение требований относительно предыдущего минималистичного layout.
