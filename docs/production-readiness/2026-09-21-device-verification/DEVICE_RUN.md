## Исторические QA проверки на физическом Redmi

- Регистрация phone/password без OTP; введённый номер сохранён точно, `phone_verified_at=NULL`. Обновление профиля, смена аккаунтов, сохранение сессии после обновления; наблюдалось 401 → refresh 200 → retry 200.
- Картинки каталога и товара по реальным URL; квадратные изображения и placeholder, фактические bounds 478×478. Список запрашивает одну страницу вместо прежней загрузки всего каталога. Launcher icon с белым фоном и отступами проверен в маске Redmi.
- Карта: настоящие OSM tiles, popup, обязательная attribution, выбор/поиск филиала, клавиатура, empty/close/reopen, offline → ручной выбор → retry, внешнее приложение 2GIS и возврат. На320/390/430dp дополнительно проверены zoom+/zoom−/pan и отсутствие перекрытий навигацией.
- Заказ самовывоза: потеря 201 после COMMIT, фон/force-stop/запуск/повтор — один order ID и одна серверная операция. Корзина очищена, история и повторное открытие проверены. Отдельно оформлена доставка при системном шрифте 150%; выбор и форма сохранялись при 100 → 150 → 100.
- 503 и timeout после котировки: до восстановления ни одного нового заказа; повтор создал ровно один. Недоступное trusted offer дало отказ без сохранения. [Сверка с SQL](evidence/native-network-recovery.json).
- Полная заявка на услуги: клиент → назначение администратором → мастер принимает/выполняет/завершает → клиент оставляет отзыв. [Серверные IDs и доказательства](evidence/native-service-flow.json). Списки заказов, детали, заявки и recovery доступны локальному DB-admin: [native admin](evidence/native-admin-orders.json).
- Photo Picker: холодный старт и пересоздание Activity, выбор только собственного QA-файла, возврат и preview. Исправлен сбой unregistered ActivityResultLauncher. Отказ камеры/отмена не блокируют каталог; реальные личные фотографии не снимались и не копировались.
- Бонусы: native баланс 137 соответствует 13700 minor на сервере, QR и возврат яркости, награда 50 minor отображается 0,50. После исправления native URLSearchParams фильтр spent даёт пустое состояние, следующая страница отправляет cursor. После входа покупателя журнал мастера недоступен. [Финальный повтор](evidence/native-final-pass.json).
- Исправлен возврат после входа: из заявки пользователь возвращается в заявку; гостевая корзина сохраняется и вход возвращает к checkout с контактами. Небезопасные returnTo и auth loops отклоняются.
- Системная dark mode сохраняет читаемую светлую тему. Cold starts 569/554/532 ms; warm Activity starts 179/163/150 ms — это Activity time, не полная готовность сетевых данных. 10 циклов навигации/фона сохранили PID, crash buffer пуст; PSS 282669–289756 KB, финал 284948 KB. Это ограниченный прогон, не доказательство отсутствия любой долгосрочной утечки.
