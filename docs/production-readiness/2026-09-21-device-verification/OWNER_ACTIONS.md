# Осталось до Google Play

Android — текущая платформа; iOS отложен владельцем.

Уже выполнены Git/main, новый Railway API, общая база сайта без Bazaar, перенос3аккаунтов, production-администратор, публичная админка, реальная доставка Telegram/кнопка статуса, подписанный AAB и установка production APK на Redmi. Повторного разрешения на эти действия не требуется.

1. **Утвердить тексты и бизнес-правила.** Privacy, terms, deletion/retention, правила лояльности и спорные случаи округления/возвратов; указать юридическое лицо, сроки и основания хранения, обработчиков и контакты. [Проекты и конкретные вопросы](../2026-09-18-remediation/OWNER_ACTIONS.md). HTTPS `/delete-account` опубликован, но до утверждённой политики сервер не выполняет удаление. Тестовые тексты в production не публиковались.
2. **Назначить поддержку и процедуру восстановления.** Администратор уже создан. Нужны ответственный сотрудник, независимая проверка владельца аккаунта и безопасный канал передачи одноразовой ссылки. Также завершить review legacy администраторов/сессий; никаких массовых удалений или бонусных перерасчётов не проводилось.
3. **Подтвердить данные и интеграции.** Адреса/контакты/часы6филиалов, недостающие3фотографии и описания каталога. Наличие по согласованию владельца уточняется через WhatsApp, stock adapter больше не условие этого выпуска. Для программы бонусов нужны утверждённые правила и POS-сверка; для пользовательских фото — реальный media provider с обработкой/удалением.
4. **Play Console.** Сохранить защищённую копию upload key и credentials. Подтвердить package `kg.avantehnik.app`/Play App Signing, загрузить готовый AAB во внутренний трек, установить store-generated APK и проверить обновление. Заполнить Data safety, audience/content/ads, review credentials покупателя/мастера и проверить применимость testing gate к типу/дате developer account. Доступа к Console для выполнения этих действий в текущем окружении нет.
5. **Оставшиеся испытания.** 16KB runtime, полный TalkBack/матрица экранов, второй Android для бонусной гонки, budget производительности, release network/SDK inventory и crash monitoring. Точные незакрытые критерии — [CRITERIA.csv](CRITERIA.csv).
