# Карта: источник, смена провайдера и границы проверки

Предыдущий 2GIS embed жёстко задаёт popup minWidth/maxWidth385 и padding60; на320/390px его активный текст обрезается. Полноценный [2GIS RasterJS](https://docs.2gis.com/en/maps/others/rasterjs/overview) требует доступ к tiles. Ключ не предоставлен.

Использованы [Leaflet1.9.4](https://leafletjs.com/examples/quick-start/) с официальными SRI и реальные tiles OpenStreetMap. Координаты всех6 точек получены из публичных2GIS карточек, не вычислены по догадке: [полная привязка](evidence/branch-coordinates.json). Внешний переход по-прежнему открывает выбранную фирму в2GIS. Адрес Баткена на дату проверки — Шабдан баатыра19. Телефоны/часы требуют подтверждения владельца.

[Политика OSM tiles](https://operations.osmfoundation.org/policies/tiles/): сохранена видимая атрибуция; стандартный HTTPS endpoint и браузерный кэш, нет bulk/offline prefetch, keepBuffer0. Native WebView идентифицируется Avantehnik/1.0 + URL сайта; web сохраняет Referer. Ресурсы CDN закреплены версией/SRI. Тест выполнен обычным headed Chrome на нескольких видимых viewport, без массового обхода/масштабирования tiles. Геолокация приложением не запрашивается: внешняя навигация передаёт фирму, доступ к координатам устройства управляется внешним приложением. Самостоятельная native геолокация не объявляется проверенной функцией.

UI-07 сохраняет исходную формулировку и вес. Историческая метка `WEB + REAL 2GIS` не описывает новый renderer целиком: фактически WEB + REAL OSM tiles + REAL2GIS coordinates. Это явно раскрытая замена реализации/средства проверки, не исключение критерия. Нет обрезки popup/control, размеры320/390/430, fallback и retry проверены [фактически](evidence/visual.json). D10 остаётся IMPLEMENTED, NOT VERIFIED до native acceptance.

В privacy/Data safety проект нужно включить сетевые обращения к CDN/OSM/2GIS и соответствующие параметры передачи. Эти уточнения не опубликованы как действующая юридическая политика. Перед публикацией владелец подтверждает применимость условий выбранного картографического сервиса к реальной нагрузке; стандартный публичный tiles service не обещает SLA.
